# Draft Twilio Consumer Trust Answers

## Are you a developer, and what are you building?

Yes. I am developing and testing a small AI-assisted voice demo using Twilio Programmable Voice. The application is a Node.js webhook that handles authorized inbound test calls and can optionally use a local Ollama model to generate a short response.

## What Twilio products do you plan to use?

Initially, Twilio Programmable Voice only.

## What types of calls will be made?

The initial scope is inbound development/testing calls only. Test participants will be myself and/or people who explicitly agree to participate. There is no bulk outbound dialer, telemarketing, advertising, lead generation, or unsolicited calling feature.

## Who are the callers/recipients?

Only the account holder and explicitly consenting testers during the review/testing phase.

## Sample call

The system begins with: “Hello. This is the Freebot Voice AI development demo. This call is for authorized testing only. How can I help you?”

## Is there a project that can be reviewed?

Yes. This GitHub repository contains the source code, architecture, consent policy, security notes, and test plan. Screenshots of the running application and test results should be attached after they are captured from the real development environment.
