Voice Prototype

Freebot Voice AI Lab

A small Twilio Voice experiment that connects speech input to a local Ollama model.

How it works

Twilio sends an inbound call to the Node.js webhook, which gathers speech and returns a TwiML response.

Voice

Twilio Programmable Voice with TwiML speech gathering.

Local AI

Ollama is optional. If it is offline, the call still receives a simple fallback response.
